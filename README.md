NusaStat is an original national statistics site for Indonesia: a dashboard of headline indicators plus pages for population, economy, health, education and all 38 provinces, with hand-drawn SVG charts and every figure sourced and dated (BPS / World Bank, 2019–2024). It is plain static files with no build step and no network requests — open it in any browser, on desktop or phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
